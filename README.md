# Amazon Clone

A frontend recreation of the Amazon homepage
built using HTML5 and CSS3.

## Technologies Used
- HTML5
- CSS3

## Features
- Navigation bar
- Search bar
- Hero banner
- Product category sections
- Product images
- Amazon-inspired layout

## Project Structure

- index.html - Main webpage
- style.css - Styling
- Image files - Website assets

## How to Run

1. Download or clone this repository.
2. Open index.html in your browser.

## Purpose

Created as a frontend development practice project.

This project is not affiliated with Amazon.
